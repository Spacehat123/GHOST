# Ghost Industry Templates Catalog & Structural Reference Matrix

> **Core Operating Rule for Ghost:**  
> These templates serve as **structural blueprints and visual architecture references**, NOT for copy-pasting template demo placeholders. When scouting or building for a prospect, Ghost references the layout, section hierarchy, and primary conversion mechanics of the designated template, then reconstructs the demo using the prospect's verified real assets (actual photos, true menu/services, exact phone/hours, and real or zero reviews).

---

## Template Decision Framework: How Ghost Selects the Best Template

When analyzing a prospect during reconnaissance, Ghost executes this 3-factor evaluation:

```
[Prospect Sub-Niche & Average Ticket Size] 
          + 
[Primary Operational Bleed / Gap] 
          + 
[Single Highest-Converting Action]
          ▼
   Matched Blueprint
```

1. **Transaction Velocity & Ticket Size:**
   - **High-Ticket / Experiential ($100+ per visit):** Choose editorial, unhurried, multi-course / bespoke styling architectures (*LuxDin*, *Solanki Atelier*, *Habité*, *LuxHotel*).
   - **High-Velocity / Local Convenience ($10–$50):** Choose conversion-first, direct-action architectures (*Cuisine*, *Pepper*, *QuickFix*, *SweetCrumb*).
2. **Primary Conversion Bottleneck (The Gap):**
   - If the prospect loses revenue because customers can't book on WhatsApp without waiting -> Select 1-tap WhatsApp Concierge architectures (*LUXÉ*, *LuxDin*, *SacredStays*).
   - If customers don't know schedule/timing -> Select live schedule / slot-picker architectures (*Drivox*, *Private Tutor*).
   - If emergency / urgent -> Select instant phone call hero (*QuickFix*, *Plumbex*).
3. **Aesthetic Material & Nav Architecture:**
   - Dark/Cinematic (*Captura*, *Bramble*, *CoachVerse*, *Gymnastic X*)
   - Minimalist Editorial Solid (*LINÉA*, *LuxDin*, *ZahrahPhoto*)
   - Floating Pill Coastal (*SOLENE*, *Solena*, *Brightside*)
   - Classic Institutional (*Lawli*, *Harlow & Partners*, *Houses&Flats*)
